# Fonds d'écran / Backgrounds

**FR —** Dépose ici des images (`.png`, `.jpg`, `.webp`) — elles apparaissent dans Hanami
(création/édition de personnage → menu « Fond »).

Sans fond choisi, Hanami affiche un dégradé sombre par défaut.

**EN —** Drop images here (`.png`, `.jpg`, `.webp`) — they show up in Hanami (character
creation/editing → "Background" menu).

With no background chosen, Hanami shows a dark gradient by default.
