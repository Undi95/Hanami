# Portraits 2D / 2D Portraits

**FR —** Ce dossier est rempli tout seul : importer une carte SillyTavern (un PNG) y range
l'image de la carte sous le nom du personnage créé (`<id>.png`).

Un personnage **sans modèle 3D (VRM)** affiche son portrait dans la scène, à la
place de l'avatar. Choisir un VRM le remplace ; supprimer le personnage efface
son portrait.

**EN —** This folder fills itself: importing a SillyTavern card (a PNG) files the card's
image under the created character's name (`<id>.png`).

A character **with no 3D model (VRM)** shows its portrait in the scene, standing in for the
avatar. Picking a VRM replaces it; deleting the character erases its portrait.
